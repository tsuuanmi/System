# Proposals

Proposals hold changes being discussed or delivered; **nothing here is a shipped feature or accepted specification merely because it is written down**. A proposal must have its own immutable ID, lifecycle status, and short summary. Move accepted, current facts to the appropriate canonical area before retiring a proposal.
