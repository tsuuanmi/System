# Classifier JSON Schemas

Generated from the zod schemas of [`src/schema.ts`](../src/README.md) by `node packages/classifier/src/generate.ts`;
never edited by hand (a test fails when they drift). `question.schema.json` is the question file,
`classification.schema.json` the `classification@1` content, and [answers](answers/README.md) the model's answer per question.
