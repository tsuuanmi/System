# What the driver imports

From System 1's provider-core: [answer-text.ts](answer-text.ts) (when a Copy
is the rendered answer), [errors.ts](errors.ts) (`ProviderError` and its kinds), [web-turns.ts](web-turns.ts)
(the Deep research state, `Sources:`) and [driver.ts](driver.ts) (the driver's types).
`completion.ts` (the two-clock wait) and the rest of the legacy turn's clocks and
presets went with it (WW2-iv). From libs: [canonical.ts](canonical.ts)
(the map's content address), [files.ts](files.ts) (`writeFileDurable`,
`ensurePrivateDir`) and [util.ts](util.ts) (`sleep`).
