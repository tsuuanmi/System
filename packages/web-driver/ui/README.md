# The ChatGPT UI map

[chatgpt-web.ui.yaml](chatgpt-web.ui.yaml) is System 1's map of chatgpt.com
(`ui-map@1.3`, last checked against the live site by System 1 on 2026-10-11):
elements with ordered candidates, actions with postconditions, states,
passive network signals and error rules. A site change is a change here.
[ui-map.v1.json](ui-map.v1.json) is the schema it is loaded against.
